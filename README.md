# ConnectHub - Full-Stack Multimedia Social Media Platform
Built for the **CodeAlpha Web Development Internship - Task 2**.

ConnectHub is a responsive full-stack social network designed to run seamlessly in offline environments.

## 🛠️ Technology Stack
- **Backend:** Python Django Framework
- **Frontend:** HTML5, Vanilla JavaScript, CSS Variables
- **Database:** SQLite Engine

## ✨ Core Features
- **User Authentication:** Complete secure register, login, and logout tracking matrix.
- **Multimedia Feed:** Main timeline supporting user text posts, images, and native HTML5 video player integrations.
- **Social Graph Engine:** Complete asymmetrical follow/unfollow connection network with active follower counters.
- **Interactive Engagements:** Collapsible comment trays driven by Vanilla JavaScript and live post like counts.
- **TikTok-Inspired Cyber Theme:** Premium deep-obsidian UI layout featuring sharp neon-crimson interactive buttons.
- **Offline Bilingual Switcher:** Dropdown menu that translates all template labels instantly between English and Tamil using client-side JavaScript.
